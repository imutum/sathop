# SatHop 质量优化与验证记录

本次改动以生产环境对应的 **v1.0.18 / 6a2aa79** 为基线，工作分支为 `codex/quality-hardening`。开始时本地停留在 v1.0.8，已先同步后续版本的已有修复，再实施本次优化。

| 范围 | 已完成的改动 | 验证 |
| --- | --- | --- |
| 下载完整性 | Worker 仅在 416 响应明确声明的总长度等于临时文件长度时认定完成；不匹配时重新请求。验证续传偏移、响应范围与最终长度；服务器忽略 Range 时重置进度。 | 正常续传、无临时文件、过期临时文件、错位范围、截断响应、200/206 重启下载回归测试。 |
| 分段下载 | Receiver 从最后实际写入的位置续传；验证 Content-Range 和对象大小，禁止跨分段写入。失败或取消时先取消并等待其他分段退出，再关闭、删除临时文件。 | 真实 HTTP 中断续传测试；并发失败、调用方取消、范围越界与对象大小变化测试。 |
| 数据库通知 | 最多 256 个通知组成一次数据库调用，并合并完全重复的通知。发送超时重新连接并重排队；监听连接断开时重新订阅并刷新相关页面数据。 | 202 个通知合为 1 次调用、保留 3 个不同载荷的单元测试；真实 PostgreSQL 通知集成测试。 |
| 实时页面 | SSE 恢复后立即刷新遗漏的数据；失败时采用带随机抖动的退避重连；频繁通知不会反复取消慢查询。 | 6 项前端回归测试；本地浏览器实际断线、恢复检查。 |
| 大批次操作 | 追加数据粒只按本次输入的 ID 查询重复项，并分块处理，避免把整个历史批次的 ID 拉入内存。分页排序增加 ID 作为相同时间戳的排序依据。 | 跨查询分块的重复 ID 测试；相同时间戳的分页测试。 |
| 页面体验 | 总览区分加载中、加载失败和空数据；失败时提供重试；节点在线状态随时间更新；暂停批次有明确标记并隐藏不适用的预计完成时间。断线提示改为不遮挡操作的横条。 | 桌面及 390px 窄屏浏览器检查；断线期间仍可切换已加载的页面。 |
| 文件访问边界 | SPA 文件响应限制在前端目录内，拒绝编码的父目录、反斜杠和空字符越界路径。 | 独立于前端构建的本地请求测试：越界返回 404，正常静态文件及页面路由继续工作。 |
| 持续集成 | CI 增加前端回归测试，并在既有 PostgreSQL 服务上执行数据库专用测试，避免这些测试长期被跳过。 | 本地对应命令全部通过。 |

v1.0.19 发布前完整后端测试连接本地独立 PostgreSQL，**835 项通过，无跳过**。前端 **219 项通过**，`npm run build`、Ruff lint/format、Pyright 及 `git diff --check` 均通过。前端构建仍有依赖包 `reka-ui` 中既有的 Rollup 注释提示，不影响构建。

本地压测使用独立 PostgreSQL 16 容器、2 个 orchestrator 进程、12 个模拟 worker、3 个模拟 receiver，预置 3,000 条任务。结果为约 **31.2 秒交付 1,087 条、客户端错误 0、健康接口 P95 496.4ms、最大 872.8ms**，通过设置的门槛。这是模拟调度 API 的验收数据，未进行同机旧版对照，也不代表实际遥感文件的网络下载速度。

初轮生产检查为只读：当时服务版本 v1.0.18，容器健康；最近 24 小时抽样日志的 2,875 条 HTTP 请求均为 200。节点长时间无心跳已由用户确认为暂时停用保留。随后经用户授权，在备份数据库、配置和旧版本后部署了 v1.0.19，健康检查通过，原有批次状态和计数一致。浏览器预览使用独立本地数据库和合成数据。

改动没有新增运行依赖、数据库迁移或对外协议字段。HTTP 范围处理参照 [RFC 9110 Content-Range](https://www.rfc-editor.org/rfc/rfc9110.html#name-content-range)；并发取消处理核对了 [Python asyncio.gather 文档](https://docs.python.org/3/library/asyncio-task.html#asyncio.gather)。

v1.0.21 继续改善自营交付体验：新增数据粒 ID 搜索和按实际保留明细分页；提供交付建议与 CSV 报告；普通失败重试避开已停止任务；修复阶段统计遗漏失败/停止任务的问题。新增接口保持既有列表接口兼容，没有新增依赖或数据库迁移。旧镜像以非 root 用户运行时发现依赖缓存权限问题，新 entrypoint 增加可写缓存回退，生产 Compose 显式指定持久缓存目录。

本轮完整验证为 **874 项后端测试通过（含 PostgreSQL，无跳过）、227 项前端测试通过**；Ruff、Pyright、前端构建和 shell 语法检查通过。新增 39 项后端用例覆盖 SQLite/PostgreSQL 搜索、分页、重试范围、报告分块、认证和公式前缀处理。报告的历史保留边界与具体操作见 [自营数据服务操作流程](operator-service.md)。

桌面及 390px 窄屏浏览器验收通过：从末页搜索、错误筛选、指定数据粒链接、单条重试和报告下载可用。窄屏筛选条挤压标题的问题已修复；最终代码构建通过，浏览器控制台未发现错误。
