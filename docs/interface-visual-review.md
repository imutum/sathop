# 控制台视觉复查 · 2026-09-27

## 设计基准

- 雾白与墨色作为两套背景，矿物绿用于主要操作与选中态；警告、失败保留独立语义色。
- 用字号、留白和表面层次建立主次，避免高亮边框、过小文字和大面积危险色。
- 复用品牌图形、页面标题、卡片、输入控件、表格与弹窗样式，避免各页面重复定义。
- 总览先展示阶段总量，细分状态按需展开；技术参数保留在提示或高级说明中。
- 弹窗标题与关闭按钮固定，长内容在内部滚动，操作栏保持可见。窄屏预留两侧边距。

## 修正的问题

- 深色模式中无显式颜色的边框继承文字色，导致对比过强。
- 固定宽度弹窗在手机溢出，长表单标题和操作区不便访问。
- Esc 和点击外部的异步确认未及时阻止关闭；关闭图标、取消按钮绕过未保存提醒。
- 嵌套导入弹窗层级高于确认弹窗，确认界面可能被遮挡。
- 任务包详情操作区和表格在窄容器溢出，文件列表挤压代码预览。
- 设置页将普通环境变量显示为警告徽标，次要信息抢占注意力。
- 侧栏项目超出常见桌面高度、手机筛选控件挤压、页面出现重复滚动条。
- 后端允许省略任务包输出配置，但详情页直接访问该字段时报错；现在显示与后端一致的默认目录和扩展名范围。

## 第二轮：布局与信息层级

在统一主题之后，再次逐页查看实际界面与主要弹窗。本轮着重改善首屏构图与阅读顺序：

- 总览以真实的已交付 / 总数据粒比例绘制环形图，四个阶段数量保持可见；节点卡片按内容自然高度排列，速率与预计剩余改为轻量分隔布局。
- 交付台账保留常驻搜索，将批次与日期筛选收进可展开区域，并显示已生效的条件数量。汇总合为一组，手机使用逐条记录，完整校验值可展开与复制。
- 新建批次按“任务设置 / 输入数据”分区，模板和运行参数按需展开。任务包加载完成前不再闪现“暂无任务包”。
- 设置采用信息主栏与说明侧栏；健康诊断在无活动、无超时时并排显示两个状态区域，出现明细时恢复宽表格。
- 批次状态说明与操作在桌面横向排列，减少重复留白；任务包输入表头使用中文业务名称。
- 节点名称提供可聚焦按钮，勾选框带节点名称；展开控件补齐键盘焦点样式。
- 修正退出登录后浏览器标题仍显示上一业务页面的问题，登录与路由标题由实际认证界面统一管理。

本轮复查涵盖表中全部页面、批次四个页签、新建/模板/CSV 嵌套弹窗、任务包上传、共享文件上传与替换、两类节点接入、工作节点抽屉和批量并发弹窗。实际验证筛选收起后仍生效、手机文件校验值展开、未保存确认以及登录前后的标题切换。浅色、深色与 390 像素布局分别检查。前端 281 项测试及生产构建通过。
